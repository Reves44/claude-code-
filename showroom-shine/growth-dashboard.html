Connect your accounts

Keys are saved only in this browser (localStorage). They are never written into the page file, so keep this dashboard on a device you trust.

Instagram

Use a long-lived token for a Business or Creator account from the Meta developer dashboard (Instagram API → “Generate token”). Needs instagram_business_basic; add instagram_business_manage_insights for daily follower history. The dashboard refreshes the token automatically so it doesn't expire.

Base44

In Base44 open your app → Settings / API to copy the App ID and API key. The built-in users entity is called User.
